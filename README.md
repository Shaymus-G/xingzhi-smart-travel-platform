# 行知 XingZhi

基于大模型、多源数据与个性化智能推荐的智慧文旅服务平台。


## 项目简介

本项目为南开大学计算机学院实习实训课程项目。

项目旨在利用：

- 大语言模型
- 多源旅游数据
- 推荐算法
- 移动端应用技术

构建智能化旅游服务平台。


## Features

- 景点推荐
- 个性化旅游规划
- AI旅行助手
- 多源旅游数据融合
- 商家服务
