# 个性化推荐模块 — 前端对接文档

## 新增接口（4 个）

### 1. 周边城市推荐

```
GET /api/recommend/nearby?city_id=257&radius_km=200&limit=8
```

**参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| city\_id | 必填 | 当前城市 ID |
| radius\_km | 200 | 搜索半径（km），范围 50-500 |
| limit | 8 | 返回数量，最大 20 |

**响应**：

```json
{
  "code": 0,
  "data": [
    {
      "city_id": 258,
      "city_name": "绍兴",
      "province": "浙江省",
      "distance_km": 41.9,
      "level": "热门",
      "cover_image": "https://..."
    }
  ]
}
```

**使用场景**：城市详情页底部，展示"从这里出发，还能去周边这些城市"。

---

### 2. 相似城市推荐

```
GET /api/recommend/similar?city_id=257&limit=8
```

**响应**：

```json
{
  "code": 0,
  "data": [
    {
      "city_id": 300,
      "city_name": "青岛",
      "province": "山东省",
      "level": "热门",
      "score": 8.5,
      "reason": "同区域、同热度等级、景点类型相似(4类重合)",
      "cover_image": "https://..."
    }
  ]
}
```

**相似度判断依据**：同地理区域 + 同热度等级 + 景点类别 Jaccard 重合度。

**使用场景**：城市详情页底部，"喜欢杭州的人，也会喜欢这些城市"。

---

### 3. 反差城市推荐

```
GET /api/recommend/contrast?city_id=257&limit=8
```

**响应**：

```json
{
  "code": 0,
  "data": [
    {
      "city_id": 50,
      "city_name": "哈尔滨",
      "province": "黑龙江省",
      "level": "小众",
      "score": 9.2,
      "reason": "不同区域、热门→小众、新鲜类型(4类)",
      "cover_image": "https://..."
    }
  ]
}
```

**反差判断依据**：不同区域 + 热度等级差异 + 景点类型差异最大化。

**使用场景**：城市详情页底部，"想换个完全不一样的地方？试试这些"。

---

### 4. 协同过滤推荐（需登录）

```
GET /api/recommend/collaborative?limit=8
Authorization: Bearer <token>
```

**响应**：格式同上，reason 为"相似用户也收藏了"。未登录返回空列表。

## 前端集成建议

### 城市详情页布局

在 `pages/city/detail.vue` 底部增加三个推荐区域：

```
┌─────────────────────────┐
│     城市详情内容          │
├─────────────────────────┤
│ 🔍 周边城市              │  ← GET /api/recommend/nearby
│ [绍兴] [嘉兴] [湖州] ...  │     横向滑动卡片
├─────────────────────────┤
│ ❤️ 相似城市              │  ← GET /api/recommend/similar
│ [青岛] [烟台] [威海] ...  │
├─────────────────────────┤
│ 🎲 换个口味              │  ← GET /api/recommend/contrast
│ [哈尔滨] [长沙] [沈阳]... │
└─────────────────────────┘
```

### API 封装（参考现有 api/travel.ts 风格）

```typescript
// api/recommend.ts
import { request } from './request'

export function getNearbyCities(cityId: number, radiusKm = 200, limit = 8) {
  return request.get('/api/recommend/nearby', { city_id: cityId, radius_km: radiusKm, limit })
}

export function getSimilarCities(cityId: number, limit = 8) {
  return request.get('/api/recommend/similar', { city_id: cityId, limit })
}

export function getContrastCities(cityId: number, limit = 8) {
  return request.get('/api/recommend/contrast', { city_id: cityId, limit })
}

export function getCollaborativeRecommendations(limit = 8) {
  return request.get('/api/recommend/collaborative', { limit })
}
```

## 注意事项

1. 推荐接口**不需要登录**（协同过滤除外），直接用 city\_id 调用
2. 如果 city\_id 不存在或坐标为空，返回 `code=1` + 错误消息
3. 三个推荐可以**并行请求**，互不依赖
4. 点击推荐城市的卡片，跳转到对应城市的详情页 `pages/city/detail?id={city_id}`
