  当前 plan_validation.py:
    validate_plan_resources():
      scenic_by_id: dict[int, dict]   → 校验 scenic_spot ID

      restaurant_by_id: dict[int,dict] → 校验 restaurant ID

  校验规则:
    - entertainment: ID必须存在于entertainment_by_id
    - shopping_mall: ID必须存在于mall_by_id
    - 类型与ID不匹配 → error (不降级)
    - general_activity 含 resource_id → warning
    - 不存在ID → error (不降级, 整个计划拒绝)

  推荐策略: 方案A — 校验失败整个计划拒绝，带错误重试模型。
