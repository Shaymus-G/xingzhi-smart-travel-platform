4. 后端收藏契约
────────────────────────────────────────────────────────────────────────────────
  Favorite ORM: id, user_id, target_type (str), target_id, created_at
  无唯一约束 → 允许重复收藏（Python 层 is_favorited 检查）
  Create Schema: target_type (str, max_length=50), target_id (int)
  Response Schema: id, user_id, target_type, target_id, created_at
  取消收藏: DELETE /api/social/favorites/{favorite_id} (JWT, 校验 user_id)
  收藏列表: GET /api/social/favorites?skip=0&limit=20 (JWT)
  重复收藏: 409 "已收藏，请勿重复收藏"


5. 后端评论契约
────────────────────────────────────────────────────────────────────────────────
  Review ORM: id, user_id, target_type, target_id, content (Text), score (Float), created_at, updated_at
  Create: {target_type, target_id, content, score?} (JWT)
  Response: id, user_id, target_type, target_id, content, score, created_at, updated_at
  列表: GET /api/social/reviews?target_type=X&target_id=Y&skip=0&limit=20 (无需认证)
  mine: GET /api/social/reviews/mine?skip=0&limit=20 (JWT, 含 target_name/target_image)
  编辑: PUT /api/social/reviews/{id} (JWT, 校验 user_id)
  删除: DELETE /api/social/reviews/{id} (JWT, 校验 user_id)
  评分范围: 0-5 (Optional, ge=0, le=5)

15. 登录和 401 行为
────────────────────────────────────────────────────────────────────────────────

  组件内 useUserStore().isLoggedIn 判断:
    未登录 → 收藏按钮显示 "登录后收藏" → @tap 跳转登录页
    未登录 → 评论表单显示 "登录后评论" → @tap 跳转登录页

  登录页路径: /pages/auth/login


16. 评论输入校验
────────────────────────────────────────────────────────────────────────────────
  与后端对齐:
    score: 1-5, 默认 5 (后端 ge=0 le=5)
    content: 必填, trim 后非空 (后端 Text 无 max_length 约束)
  提交期间: reviewSubmitting=true, 按钮禁用
  失败: 保留输入, Toast 错误
  成功: 清空输入, refresh 评论列表, Toast "评论成功"
