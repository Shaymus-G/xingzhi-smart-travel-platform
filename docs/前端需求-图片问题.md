## 线上旅游资源图片数据问题

前端在连接：

```
https://xingzhi-smart-travel-platform.onrender.com
```

时发现大量城市和景点显示默认图。经检查，问题不是前端 URL 拼接，也不是图片 CDN 失效，而是接口返回的图片字段为空。

已确认的样例：

| id   | 名称         | 图片字段           |
| ---- | ------------ | ------------------ |
| 4    | 关林景区     | `image_url = null` |
| 5    | 神都十三坊   | `image_url = null` |
| 6    | 定鼎门南广场 | `image_url = null` |

抽样结果：

- 前 100 条景点中，97 条 `image_url` 为空；
- 前 50 条城市中，47 条 `cover_image` 为空；
- 有 URL 的样本均为有效 HTTPS 图片，返回 `200 image/jpeg`；
- 酒店和餐厅接口当前返回 0 条，需要确认线上表是否为空或导入不完整。

请先检查线上数据库实际数据量：

```
SELECT COUNT(*) AS total FROM cities;
SELECT COUNT(*) AS total FROM scenic_spots;
SELECT COUNT(*) AS total FROM hotels;
SELECT COUNT(*) AS total FROM restaurants;
```

检查缺图数量：

```
SELECT
    COUNT(*) AS total,
    SUM(
        CASE
            WHEN cover_image IS NULL OR TRIM(cover_image) = ''
            THEN 1 ELSE 0
        END
    ) AS missing_images
FROM cities;
SELECT
    COUNT(*) AS total,
    SUM(
        CASE
            WHEN image_url IS NULL OR TRIM(image_url) = ''
            THEN 1 ELSE 0
        END
    ) AS missing_images
FROM scenic_spots;
SELECT
    COUNT(*) AS total,
    SUM(
        CASE
            WHEN image_url IS NULL OR TRIM(image_url) = ''
            THEN 1 ELSE 0
        END
    ) AS missing_images
FROM hotels;
SELECT
    COUNT(*) AS total,
    SUM(
        CASE
            WHEN image_url IS NULL OR TRIM(image_url) = ''
            THEN 1 ELSE 0
        END
    ) AS missing_images
FROM restaurants;
```

请确认之前的数据工程图片填充脚本是否已经对线上数据库执行。

图片回填要求：

- 回填脚本应支持重复执行；
- 只填充空字段，不覆盖已经有效的 URL；
- 写入可公开访问的 HTTPS URL；
- 不写入 localhost、Windows 本地路径或临时文件路径；
- 回填前备份或先在测试数据库执行；
- 执行后抽样验证 HTTP 状态码和 `Content-Type`；
- 返回填充总数、失败数和剩余空值数。

不建议简单随机拼接不存在的 Unsplash URL。应使用现有合法数据源、项目已有图片填充脚本或稳定对象存储。





## 前端联调所需后端支持

### 一、确认 Render 使用的数据库

当前线上接口存在以下现象：

- 城市和景点大量图片字段为空；
- 酒店列表返回 0 条；
- 餐厅列表返回 0 条；
- 本地数据库的数据量与线上接口表现不一致。

请确认 Render 环境中的：

```
MYSQL_HOST
MYSQL_PORT
MYSQL_USER
MYSQL_DATABASE
```

是否指向完整导入后的 TiDB/MySQL 数据库。

请在后端日志或数据库中确认：

```
SELECT DATABASE();
SELECT COUNT(*) FROM cities;
SELECT COUNT(*) FROM scenic_spots;
SELECT COUNT(*) FROM hotels;
SELECT COUNT(*) FROM restaurants;
```

请检查是否只导入了部分种子数据，而没有导入完整旅游资源数据和图片数据。

### 二、图片接口要求

以下接口返回的图片字段应保持一致：

```
GET /api/travel/cities
GET /api/travel/cities/{city_id}
GET /api/travel/scenics
GET /api/travel/scenics/{scenic_id}
GET /api/travel/hotels
GET /api/travel/restaurants
```

图片字段为空时应返回：

```
{
  "image_url": null
}
```

不要返回：

```
"None"
"undefined"
""
"http://127.0.0.1/..."
```

如果接口支持分页，建议响应中增加：

```
{
  "data": {
    "items": [],
    "total": 10000,
    "skip": 0,
    "limit": 20
  }
}
```

这样前端能够判断线上数据库的真实数据量，而不是只能检查当前页。
