# 后端对接数据库指南

## 一、获取数据库文件

数据库文件路径：`data/xingzhi.db`

直接把这个文件发给后端同学即可。它是一个 SQLite 数据库，无需安装任何数据库服务器。

## 三、后端连接方式

### 方式一：Python（推荐 - 使用 SQLAlchemy）

```python
from sqlalchemy import create_engine, Column, Integer, String, Float, Text, DateTime, ForeignKey
from sqlalchemy.orm import declarative_base, sessionmaker

# 连接数据库
engine = create_engine("sqlite:///path/to/xingzhi.db")
Session = sessionmaker(bind=engine)
session = Session()

# 查询示例：获取北京的所有景点
cities = session.query(City).filter(City.name == "北京").all()
if cities:
    beijing = cities[0]
    spots = session.query(ScenicSpot).filter(ScenicSpot.city_id == beijing.id).all()
    for spot in spots:
        print(f"{spot.name} - {spot.address}")

# 查询示例：获取某个城市的酒店，按评分排序
hotels = (
    session.query(Hotel)
    .filter(Hotel.city_id == beijing.id, Hotel.score != None)
    .order_by(Hotel.score.desc())
    .limit(10)
    .all()
)
```

### 方式二：Python（直接使用 sqlite3）

```python
import sqlite3

conn = sqlite3.connect("path/to/xingzhi.db")
conn.row_factory = sqlite3.Row
cur = conn.cursor()

# 查询城市及其景点
cur.execute("""
    SELECT c.name AS city, s.name AS spot, s.address, s.category
    FROM cities c
    JOIN scenic_spots s ON c.id = s.city_id
    WHERE c.name = ?
    LIMIT 20
""", ("北京",))
rows = cur.fetchall()
for row in rows:
    print(dict(row))

conn.close()
```

## 四、常用 API 查询示例

### 1. 首页 - 获取热门城市列表

```sql
SELECT id, name, province, latitude, longitude
FROM cities
ORDER BY name
LIMIT 20;
```

### 2. 城市详情页 - 获取城市及所有POI数据

```sql
-- 获取城市信息
SELECT * FROM cities WHERE id = ?;

-- 获取该城市的景点
SELECT id, name, description, address, category, score, price, latitude, longitude
FROM scenic_spots
WHERE city_id = ?
ORDER BY score DESC NULLS LAST;

-- 获取该城市的酒店
SELECT id, name, description, address, price, score, latitude, longitude
FROM hotels
WHERE city_id = ?
ORDER BY score DESC NULLS LAST;

-- 获取该城市的餐饮
SELECT id, name, type, description, price_level, score, address, latitude, longitude
FROM restaurants
WHERE city_id = ?
ORDER BY score DESC NULLS LAST;
```

### 3. 搜索 - 按关键词搜索景点

```sql
SELECT s.*, c.name AS city_name
FROM scenic_spots s
JOIN cities c ON s.city_id = c.id
WHERE s.name LIKE '%故宫%'
LIMIT 20;
```

### 4. 搜索 - 按城市名搜索

```sql
SELECT * FROM cities WHERE name LIKE '%北京%';
```

### 5. 筛选 - 按分类获取景点

```sql
SELECT * FROM scenic_spots
WHERE city_id = ? AND category = '风景名胜'
ORDER BY score DESC NULLS LAST;
```

### 6. 筛选 - 按价格区间获取酒店

```sql
SELECT * FROM hotels
WHERE city_id = ? AND price BETWEEN 200 AND 500
ORDER BY price ASC;
```

## 五、数据关系图

```
users ────┬─── reviews ─────────── scenic_spots
          │                              │
          ├─── favorite_scenic ───────────┤
          │                              │
          ├─── travel_plans ──── cities ──┼─── hotels
          │                              │
          ├─── ai_sessions               └─── restaurants
          │
          └─── user_preference
```

- **cities** 与 **scenic_spots / hotels / restaurants** 是一对多关系（`city_id`）
- **users** 与其他表是一对多关系（`user_id`）
- **reviews / favorite_scenic** 通过 `target_type` + `target_id` 实现多态关联

## 六、注意事项

1. **SQLite 并发限制**：SQLite 适合单机开发测试。如果项目需要部署上线，建议迁移到 MySQL（已提供迁移脚本，见数据工程操作指南）。
2. **NULL 值处理**：部分字段（如评分、价格）可能为 NULL，API 返回时建议做缺省值处理。
3. **经纬度**：`latitude` 和 `longitude` 为高德地图坐标系（GCJ-02），前端地图展示时需注意坐标系转换。
4. **图片**：`image_url` 字段目前为空，需要后端同学后续补充图片资源。
5. **数据库文件位置**：`xingzhi.db` 位于项目根目录下的 `data/` 文件夹中。
